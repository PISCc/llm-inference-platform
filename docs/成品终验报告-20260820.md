## 部署阶段需要完成

### 仅公开浏览与离线问答

直接部署 `dist/index.html` 即可。HashRouter 与相对资源路径已适配静态托管。

### 启用在线模型与 PPTX

需要同时部署 Node API 服务，并完成：

1. 将 `/api/*` 与前端保持同域，或配置允许的生产来源。
2. 配置模型服务环境变量；若使用共享 API Key，应增加访问控制与限流。
3. 为 PPT 服务提供 Node、依赖模块和运行时路径。
4. 若采用多实例或 Serverless，模型会话配置需改用共享存储；单实例 Node 服务可继续使用当前内存会话。

以上属于部署架构与生产配置，不是页面功能缺失。
